# 千禧accounts 0.0.3

Windows x64 安装包。安装包未签名；升级请先正常退出旧实例（安装器会拒绝覆盖运行中的进程），实例、登录资料与扩展都会保留。

## 快捷网站栏

- 标签栏管理弹层的每一行本身就是切换目标：点整行即切到那一栏，原来的「切换」按钮已删除；行内「重命名 / 删除」仍然独立，不会误触切换。
- 标签栏支持自由拖动排序：按住行身拖过 4px 进入拖动，被拖的行浮起、其余行实时让位，松手才写回顺序（新增 IPC `quick-bar-reorder`）。拖动不会顺手切换标签栏，拖动后紧跟的那次点击也会被忽略。
- 行是键盘可达的按钮（`role="button"`、Enter / 空格即切换），并有焦点环。
- 快捷网站卡片的两种手势分开：直接左右拖动＝平移整条快捷栏；按住约 260 毫秒再拖＝浮起幽灵并调整网站顺序。平移结束后紧跟的点击不会再打开网站。

## 切换动画（对齐 U-Time 的运动语言）

- 引入 `--motion-fast/base/slow` 与 `cubic-bezier(.22,1,.36,1)` 缓动，标签栏切换按前后顺序决定「向前翻 / 向后翻 / 只淡入」，条目错峰 26ms 落位。
- 标签栏弹层有独立的入场动画（缩放 + 上移 + 淡入），关闭仍然同步，不会拖住输入。
- 弹层开着时切换的动画会攒着，等弹层关掉再播，不在看不见的地方偷偷播完。
- `prefers-reduced-motion` 下所有动画归零，切换依旧生效。
- 960px 窄窗 + 20 个快捷网站时标题行不再折行或越界（标签栏按钮加入后的布局回归）。
