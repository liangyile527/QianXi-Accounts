# 千禧accounts 0.0.2

Windows x64 安装包。安装包未签名；升级请先正常退出旧实例（安装器会拒绝覆盖运行中的进程），实例、登录资料与扩展都会保留。

## 快捷网站栏：多标签栏

- 「全部」按钮改为纯图标（地球），不再占用标题行文字位置。
- 新增「标签栏」按钮：点开可新建、切换、重命名、删除标签栏；当前栏在列表里以「当前」标记。
- 每个标签栏拥有各自独立的网站集合（每栏最多 21 个，最多 12 栏，至少保留 1 栏）。切换到新标签栏时网站条完全换一套，空栏只提示「这个标签栏还是空的，点右侧 ＋ 添加网站」，直到添加网站才出现内容。
- 删除标签栏会连同其中的网站一起删除，并二次确认；删除当前栏后自动回落到第一栏。
- 排序与拖动只在同一栏内生效，跨栏排序被拒绝，避免串栏。
- 新增 IPC：`quick-bar-save`、`quick-bar-remove`、`quick-bar-activate`；快照新增 `quickBars` 与 `quickBar` 字段，旧数据自动迁移到「标签栏 1」。

## 发布流程

- 新增 `npm.cmd run install:latest`：关闭运行中的实例 → `/S` 静默安装 → 校验已安装可执行文件 → 启动新版本。
- 新增 `npm.cmd run release:local`：构建安装包并立即安装启动。
- `AGENTS.md` 增加「生成 exe 后的收尾（强制）」规则与 `--dry-run` 用法说明。

## 版本说明

上一版安装包 `v0.0.1` 单独保留在它自己的 Release 中，本版资产不与其混放。
